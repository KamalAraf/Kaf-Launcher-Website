Features

A straightforward place to prepare, organize, and launch Minecraft Java instances.

  • Separate instances

    Keep each setup’s game directory and saves separate while reusing shared Minecraft files.

  • Vanilla and mod loaders

    Create Vanilla, Fabric, Quilt, Forge, and NeoForge instances.

  • Mod management

    Search for and install compatible mods with Modrinth, and manage installed mods.

  • Modpack imports

    Import supported `.mrpack` modpack archives into an instance.

  • Profiles and launch checks

    Use Microsoft sign-in or a local offline profile, and run launch diagnostics before playing.

  • Instance backups

    Export and restore instances as separate setups.
