Frequently asked questions

More answers can be added as the launcher and its releases are finalized.

Which mod loaders are supported?

Vanilla, Fabric, Quilt, Forge, and NeoForge instances are supported.

Can I keep separate saves for each setup?

Yes. Each instance has its own game directory for saves and other per-instance files.

Can I use an offline profile on multiplayer servers?

Yes, if the server owner has enabled offline mode and the server allows your connection. Offline profiles are not authenticated by Microsoft and cannot access servers that require an authenticated Minecraft account. Follow the server owner’s rules.

Where are the Windows, macOS, and Linux installers?

Installer links and system requirements will be posted on the Downloads page after builds are verified.
