# Kaf Launcher Website

Minimal static English-language website for Kaf Launcher, published through GitHub Pages.

Pages are Home, Features, Downloads, FAQ, Changelog, Support, Privacy, and Terms. Windows, macOS, and Linux download entries are placeholders until verified installers exist. Keep product claims aligned with the launcher source and `PRODUCT.md`.

Run the built-in site checks with:

```sh
node --test tests/site.test.mjs
```
